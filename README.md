# 🎮 ARN's Arena – Competitive Multiplayer Tic-Tac-Toe Experience

ARN's Arena is a modern multiplayer Tic-Tac-Toe platform featuring player authentication, leaderboards, player profiles, achievements, real-time score tracking, and an immersive gaming experience.

🌐 **Live Demo:**  
https://arnsarena.netlify.app/

---

## 🧠 Project Overview

Traditional Tic-Tac-Toe games often lack progression, competition, and long-term engagement.

ARN's Arena transforms the classic game into a competitive gaming platform where players can:

- Create accounts
- Track wins and matches
- Earn points
- Compete on global leaderboards
- View player profiles
- Unlock achievements

---

## ✨ Features

### 🎯 Multiplayer Tic-Tac-Toe
- Interactive 3×3 game board
- Turn-based gameplay
- Win detection system
- Draw detection
- Winning strike line animation
- Celebration effects on victory

### 👤 Authentication System
- User Registration
- User Login
- Persistent player sessions
- Secure player identification

### 🏆 Global Leaderboard
- Live ranking system
- Point-based scoring
- Match statistics tracking
- Automatic updates after every match

### 📊 Player Profile

Track personal statistics including:

- Total Wins
- Total Games Played
- Total Points
- Achievement Progress

### 🎖 Achievement System

Players can unlock achievements based on performance and participation.

**Examples:**
- 🥇 First Victory
- 🚀 Rising Champion
- ⚔ Arena Veteran
- 👑 Tic-Tac-Toe Master

### 🎨 Modern UI Experience
- Responsive design
- Dark gaming theme
- Smooth animations
- Interactive effects
- Mobile-friendly interface

### 🌙 Theme Toggle
- Light Mode
- Dark Mode
- User preference support
